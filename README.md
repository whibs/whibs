## My engineering approach

In developing these projects, I aim to make the engineering process as visible as the resulting software.

Across these repositories, I intend to emphasise:

- small, purposeful changes with a meaningful Git history that clearly explains progression;
- using test-driven development to guide implementation where appropriate;
- automated testing, static analysis and code quality checks integrated into the development lifecycle;
- continuous integration through automated builds, tests and quality checks, with pull requests used to review and validate changes;
- clear documentation of architecture, design decisions, trade-offs, test results and application behaviour, supported by diagrams and
  demonstrations where useful;
- reproducible builds and straightforward instructions for running, testing and evaluating each project.
